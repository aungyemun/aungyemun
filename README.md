## Scientific Software Projects

### [Monograph PDF](https://github.com/aungyemun/monograph-pdf)

Open-source, privacy-focused desktop PDF editor for viewing, editing, annotating, converting, organizing, and securing PDF documents offline, including optical character recognition (OCR).

### RNA-Seq Downloader

Desktop application for Linux and Windows that downloads, validates, and organizes publicly available RNA sequencing datasets from NCBI GEO, SRA, and ENA, with an emphasis on data integrity and reproducibility.

### RNA-Seq Analysis Pipeline

Reproducible RNA sequencing analysis workflows incorporating sequencing quality control, read alignment, gene quantification, differential expression analysis, and biological interpretation.

### [MultiCamApp](https://github.com/aungyemun/MultiCamApp)

Offline multi-camera recording and video verification software for Windows, designed for research, laboratory, and educational applications.

## Development Principles

I aim to develop scientific software that emphasizes:

* **Reproducibility:** Transparent and verifiable research workflows.
* **Reliability:** Careful testing, validation, and error handling.
* **Privacy:** Offline-first functionality and minimal unnecessary data collection.
* **Accessibility:** Practical software that is straightforward to use.
* **Open Science:** Supporting transparent scientific methods and reproducible research.
* **Continuous Improvement:** Iterative development informed by testing and user feedback.
